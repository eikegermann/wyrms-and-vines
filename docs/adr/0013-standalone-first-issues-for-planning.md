# 13. Standalone first, the Inn later; GitHub Issues for planning

- **Status:** Accepted
- **Date:** November 2026 (recorded 2026-11-22)

## Context

Wyrms & Vines began as an idea for the tournament games at the Inn in Dragon & Bard (its issue #46). Building it inside the bigger game would tie it to that game's module system and progress before the rules had been found by play.

## Decision

Wyrms & Vines is developed as a standalone game in its own repo until its rules settle. It will then move into Dragon & Bard's Inn as a tournament game, which is why the logic is kept free of the screen (ADR 0002). As in Dragon & Bard, ideas and plans live in this repo's GitHub Issues, and lasting decisions in these ADRs.

## Consequences

The game could be playtested with families straight away. Some work, such as player setup and level choice, will need to fit Dragon & Bard's profiles and settings later, which may call for a new ADR.
