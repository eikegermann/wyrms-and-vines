# Sounds for Wyrms & Vines

Put sound files in this folder with exactly these names. The game plays any that exist and skips the rest, so you can add them a few at a time.

**Format:** `.mp3` (short, ideally under 2 seconds unless noted). If you record in another format (`.wav`, `.m4a`, a voice memo), just hand the files over and they can be converted.

**More than one take:** add `-2` and `-3` versions (for example `dice-land.mp3`, `dice-land-2.mp3`, `dice-land-3.mp3`) and the game picks one at random each time, so it doesn't sound the same every roll.

| File name | When it plays | Ideas for recording |
|---|---|---|
| `dice-shake.mp3` | Dice start rolling (about 1 second) | Dice rattling in a cup |
| `dice-land.mp3` | Dice land and show the result | Dice tipped out onto a wooden table |
| `step.mp3` | Each square a token hops (plays a lot: keep it tiny and soft) | A light tap or "tok" on wood |
| `game-start.mp3` | A new game begins | A short horn, a drum roll, "Let the race begin!" |
| `game-win.mp3` | Someone reaches square 100 (can be longer, 2–4 s) | Fanfare, cheering, applause |
| `vine-rustle.mp3` | Landing on a vine's root | Rustling leaves |
| `vine-climb.mp3` | Climbing up a vine | A rising whoosh, "wheee!", quick climbing sounds |
| `vine-snap.mp3` | The vine snaps (failed vine) | Snapping a twig, a sad "oh no" |
| `wyrm-hiss.mp3` | Landing on a wyrm's head | A hiss or growl |
| `wyrm-shake-off.mp3` | Shaking off the wyrm (success) | A grumpy wyrm grumble, a "phew!" |
| `wyrm-slide.mp3` | Sliding down the wyrm (failed wyrm) | A falling slide whistle, "aaaah!" |
| `wyrm-wake.mp3` | Living forest: a wyrm wakes up and moves | A grumpy yawn, a grumble, slithering |
| `wyrm-fly.mp3` | Living forest: a wyrm flies away forever | Big wing flaps, "I've had enough!", a fading roar |
| `vine-sprout.mp3` | Living forest: a sprout appears or grows | A little "pop!", a twinkle |
| `vine-wither.mp3` | Living forest: an old vine withers and the new one shoots up | A sad creak, then a rising whoosh |
| `ants.mp3` | Iron Wyrm: an ant colony moves in | Tiny marching feet, munching |
| `egg.mp3` | Iron Wyrm: a wyrm lays an egg on a vine | A soft "plop", an ominous hum |
| `egg-hatch.mp3` | Iron Wyrm: the egg hatches and the vine becomes a fortified wyrm | An eggshell crack, then a clank of iron |
| `stomp.mp3` | Iron Wyrm: someone stomps an ant colony | A big stomp, "squish!" |
| `tunnel.mp3` | Iron Wyrm: falling down a hunter's tunnel | A falling "whooo", a thud at the bottom |
| `hunter-fight.mp3` | Iron Wyrm: a hunter beats a wyrm | Twang of a bow, a roar, a victory shout |
| `hunter-eaten.mp3` | Iron Wyrm: a wyrm eats a hunter | A gulp and a burp, then snoring |
| `correct.mp3` | A sum is right | A bright chime, "yes!" |
| `wrong.mp3` | A sum is wrong (keep it gentle!) | A soft "hmm?" or low boop |
| `duel-start.mp3` | A duel begins | Swords clashing, "En garde!" |
| `digit-place.mp3` | A digit is placed in a duel | A quill scratch, a stamp, a click |
| `duel-win.mp3` | Someone wins a duel | A short trumpet, a cheer |
| `duel-tie.mp3` | A duel ends in a tie | A "huh!", two swords clinking |
| `peace.mp3` | A duel is declined | A dove cooing, a calm harp note |

There's a 🔊/🔇 button on the setup screen and next to "Show log" during a game.

Sounds play when the game is opened from the web link (or the home-screen icon). When `index.html` is opened directly as a file, only the first take of each sound is used.
